## FAQ Section

**Headline**: Frequently Asked Questions

### About Focal Deploy

**Q: What is Focal Deploy?**
A: Focal Deploy is a CLI tool that automates the entire process of deploying applications to AWS. It handles EC2 setup, SSL certificates, DNS configuration, security hardening, and monitoring—all in one command.

**Q: Do I need AWS expertise to use Focal Deploy?**
A: No! That's the whole point. Our wizard uses plain English and guides you through every step. You just need an AWS account and your application code.

**Q: How long does deployment take?**
A: 5-10 minutes on average, compared to 4-8 hours manually configuring AWS.

**Q: What technologies does Focal Deploy support?**
A: Currently optimized for Node.js applications. Support for Python, PHP, Go, and other languages is coming soon.

---

### About Costs

**Q: How much does it cost to deploy with Focal Deploy?**
A: Focal Deploy itself costs $0-50/month depending on your plan. AWS infrastructure costs approximately $35/month for a small application (t3.small instance, 20GB storage, etc.). We provide exact cost estimates before deployment.

**Q: Are there any hidden fees?**
A: No. You pay for:
1. Focal Deploy subscription (optional, has free tier)
2. AWS infrastructure (standard AWS rates, no markup)

That's it. No surprises.

**Q: Is there a free tier?**
A: Yes! The free tier includes 1 active deployment with all core features. Perfect for trying Focal Deploy or running a single project.

---

### Technical Questions

**Q: Do I get full access to my server?**
A: Yes! You can SSH into your EC2 instance or use AWS SSM Session Manager. It's your infrastructure, you have full control.

**Q: What if I want to stop using Focal Deploy?**
A: No problem! Your infrastructure runs on standard AWS services. You can manage it manually or export the configuration to Terraform. No vendor lock-in.

**Q: What AWS services does Focal Deploy use?**
A: EC2 (server), S3 (storage), Security Groups (firewall), Elastic IP (static IP), IAM (permissions), and optionally SSM (remote access).

**Q: Can I customize the infrastructure?**
A: Absolutely. Focal Deploy uses sensible defaults, but you can customize instance type, region, storage size, security settings, and more.

**Q: What if something goes wrong?**
A: Focal Deploy includes dual access methods (SSH + SSM), automatic backups, and emergency recovery procedures. Our documentation covers common issues, and Pro/Team tiers include priority support.

---

### Security Questions

**Q: Is Focal Deploy secure?**
A: Security is built-in by default. Every deployment includes:
- SSH hardening (custom port, key-only auth)
- UFW firewall (deny-all except required ports)
- Fail2ban (intrusion prevention)
- Automatic security updates
- Let's Encrypt SSL certificates
- Security group configuration

**Q: Who has access to my AWS credentials?**
A: Only you. Credentials are stored locally on your machine using your system's secure keychain (same as your browser stores passwords). Focal Deploy never sends credentials to our servers.

**Q: What about SSL certificates?**
A: SSL certificates are automatically generated and renewed using Let's Encrypt (free, industry-standard). Certificates are stored on your EC2 instance. Renewal is automatic via cron jobs.
